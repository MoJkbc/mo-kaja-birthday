# Mo & Kaja Birthday

Static single-page birthday invite.

## Preview locally

```bash
cd /Users/monikajakubcova/Projects/mo-kaja-birthday
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

Or open `index.html` directly in a browser (all assets are inline).

## Edit

- **Copy & layout:** `index.html` (HTML + JS)
- **Styles:** `styles.css` (palette, typography, layout)
- **Images:** replace the base64 placeholders in each `.sticky-image img` `src`
